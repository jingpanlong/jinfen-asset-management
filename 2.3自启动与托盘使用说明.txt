锦纷资产管理系统 2.3.0

一、名称更新
软件窗口、登录页、关于页、提示、资产标签、软件图标、安装包及快捷方式已改为锦纷资产管理系统。
保留原有账号、资产、附件、历史、图表、模板等功能。
微信公众号：景同志；小红书：景同学。

二、开机自启动
登录页或主界面点击“运行设置”，勾选“随 Windows 登录自动启动”，保存。
也可在系统托盘图标的右键菜单开关“开机自启动”。
安装版安装时也可勾选自启动选项，默认不勾选。
自启动使用当前 Windows 用户的启动项，不需要管理员权限，不影响其他 Windows 用户。
自动启动软件不等于自动登录，软件不保存或自动输入账号密码。
默认自启动时先收起到托盘；双击托盘图标或右键“显示窗口”后，按正常流程登录。
单文件版请先放到固定目录。移动 EXE 后请重新打开运行设置保存自启动选项，更新启动路径。

三、系统托盘
主界面“缩小到托盘”按钮可收起窗口。
默认点击窗口关闭按钮会缩小到托盘，软件仍在运行。
可在运行设置中选择最小化时也收起到托盘，或取消关闭到托盘。
单击 / 双击托盘图标，或右键“显示窗口”，可以恢复窗口。
托盘右键菜单提供显示窗口、开机自启动、运行设置、关于系统、退出程序。
需要完全退出时，右键托盘图标选择“退出程序”。更新软件之前请先完全退出旧程序。
若托盘图标藏在 Windows 的通知区域内，请点击右下角向上的箭头查找。
系统托盘不可用时，软件保持窗口显示，避免收起后无法找回。
退出登录会回到登录页，不沿用上一用户的登录状态。

四、单实例
同一用户数据目录只运行一个新版实例。
再次打开 EXE 会恢复已运行的窗口，自启动重复触发时不会重复创建程序。
旧版 2.2 及以前没有此保护，升级时请先关闭旧版。

五、数据兼容
已有旧版本地数据库或连接配置时，自动沿用原 %LOCALAPPDATA%\QiyunAssets 目录，不移动或清空数据。
全新安装使用 %LOCALAPPDATA%\JinfenAssets；一旦已有新目录的数据或连接配置，优先使用新目录。
运行设置保存在实际数据目录的 desktop.json，独立于业务数据库和业务备份。
历史数据库文件路径可能带有旧英文目录名，这是兼容设计，不影响软件新名称。
已注册的账号和密码继续有效，没有预设管理员账号。
开机启动指向安装目录时，卸载会移除此程序的启动项；不会删除公司数据库、备份和运行偏好。
请升级前先创建完整备份。
